# Semiconductor Defect Intelligence

An AI-powered semiconductor manufacturing analytics platform
for defect analysis, anomaly detection, process analytics,
computer vision, RAG, and agentic AI-assisted root-cause analysis.

## Project Goal

The goal of this project is to build an end-to-end AI system
that assists semiconductor manufacturing engineers in analyzing:

- Wafer inspection images
- Manufacturing process data
- Defect patterns
- Process anomalies
- Historical engineering knowledge

The system will combine:

- Machine Learning
- Statistical Analytics
- Computer Vision
- Deep Learning
- C++
- Retrieval-Augmented Generation
- Agentic AI
- Multi-agent workflows
